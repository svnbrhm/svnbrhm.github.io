# RunningCrews.com - Global Running Community Platform

## Project Overview

**RunningCrews.com** is a Next.js-based website that connects running enthusiasts with local running crews worldwide. The project uses Airtable as a headless CMS and implements Incremental Static Regeneration (ISR) for optimal performance.

**Project Version:** 2.2  
**Last Updated:** June 26, 2025  
**Current Phase:** Phase 1 - Core Functionality (73% Complete)

## Core Features

### Primary Features
- **Running Crew Discovery:** Browse and search local running crews with detailed profiles (449 crews)
- **Interactive World Map:** Leaflet-based map showing crew locations globally
- **Event Management:** Comprehensive event listings (marathons, local runs, crew events)
- **Blog System:** Community-driven content with crew stories and running tips
- **Route Sharing:** Discover and share running routes with GPX data support
- **Global Search:** Advanced search across crews, events, blog posts, and routes
- **Statistics Dashboard:** Real-time metrics (188 cities, 60 countries)

### Technical Features
- **Performance:** ISR implementation with server-side caching for instant statistics loading
- **Responsive Design:** Mobile-first approach with optimized user experience
- **Error Handling:** Comprehensive error boundaries and fallback systems
- **SEO Optimization:** Meta tags, structured data, and performance optimization
- **Admin Panel:** Mock data monitoring and manual revalidation capabilities

## User Experience

### Target Personas
1. **Running Enthusiasts:** Individuals looking to join local running communities
2. **Crew Organizers:** Leaders managing running groups and events
3. **Event Participants:** Runners seeking races and community events
4. **Content Creators:** Contributors sharing running stories and routes

### User Flows
1. **Discovery Flow:** Homepage → Map/Search → Crew Details → Contact
2. **Content Flow:** Homepage → Blog/Events → Article/Event Details
3. **Community Flow:** Search → Results → Crew Profile → Join/Contact

## Technical Architecture

### Technology Stack
- **Frontend:** Next.js 13+, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Airtable integration
- **Mapping:** Leaflet with OpenStreetMap tiles
- **Deployment:** Vercel with automated CI/CD
- **Caching:** ISR with server-side statistics caching
- **Monitoring:** Error boundaries, mock data tracking

### Key Components
- **Layout:** Header, Footer, Navigation
- **Crew:** CrewCard, CrewDetail, CrewList, CrewStats, FeaturedCrews
- **Map:** WorldMap, WorldMapOptimized, WorldMapFast
- **Content:** Blog, Event, Route components
- **UI:** SearchBar, Statistics, Pagination, InfoCard
- **Admin:** MockDataMonitor, RevalidationPanel

### Data Models
- **Crews:** Name, location, description, contact, statistics
- **Events:** Title, date, location, type, registration
- **Blog Posts:** Title, content, author, date, categories
- **Routes:** Name, distance, difficulty, GPX data

### APIs & Integration
- **Airtable API:** Primary data source with pagination support
- **Statistics API:** Cached endpoint for performance (`/api/statistics`)
- **Search API:** Global search across all content types
- **Revalidation API:** On-demand ISR cache updates
- **Cron Jobs:** Daily statistics cache updates (3:00 AM UTC)
